# Spine Wallpaper

アークナイツの動的立ち絵を、Android のライブ壁紙として表示するアプリです。動的立ち絵は Spine というツールで作られたアニメーションで、このアプリはそれを背景画像の上に重ねて表示します。

## できること

普段は、キャラクターの待機アニメーション（Idle）を繰り返し再生します。キャラクターの上をタップすると反応のアニメーション（Interact）を一度再生し、終わると待機に戻ります。キャラクター以外の場所をタップしても、アニメーションは変わりません。

待機がしばらく続くと、特別なアニメーション（Special）をときどき再生します。再生までの時間は毎回ランダムに決まります。

背景画像とキャラクターは、ファイルを置き換えてアプリをビルドし直すと差し替えられます。キャラクターの大きさや位置も、プログラム中の数値を書き換えて調整できます。

壁紙がほかのアプリの画面に隠れている間は、描画を止めて電池の消費を抑えます。

アプリ一覧から「Spine Wallpaper」を開くと、この壁紙を設定する画面が開きます。

## 素材の扱いについて

キャラクターの素材の著作権は Hypergryph にあります。このアプリは個人で使うために作ったものです。素材を含んだアプリや、素材を置いたままのプロジェクトのフォルダーは、他人に渡したり公開したりしないでください。
