# うまく動かないとき

この文書では、これまでに実際に起きた問題と、起こりうる問題について、原因と対処を説明します。

## インストールで INSTALL_FAILED_USER_RESTRICTED と表示される

USB 経由でのアプリのインストールが初期設定では許可されていません。設定アプリのビルド番号を連打して「開発者向けオプション」を開き、「USB からインストール」をオンにしてください。

設定をオンにしたあとも、インストールのたびに端末に確認の画面が出ます。端末の画面を見ながらインストールし、確認の画面で「インストール」を押してください。

`./gradlew installDebug` や Android Studio の実行ボタンでインストールすると、この確認の画面に答える前に失敗することがありました。その場合は、[use.md](use.md) の手順 3 にある `adb install -r` を使ってください。

## 壁紙が端末の標準の壁紙に戻った

アプリを強制停止すると、端末が壁紙を標準のものに戻すことがあります。設定アプリの「強制停止」や、`adb shell am force-stop` コマンドによる停止がこれにあたります。アプリをアンインストールしたときも、同じように壁紙が戻ります。

どの場合も、[use.md](use.md) の手順 4 で壁紙を設定し直してください。

## アプリや壁紙が起動してすぐに終了する

多くの場合、原因は素材にあります。次の点を確認してください。

- `assets/character/` に `.skel`（または `.json`）、`.atlas`、`.png` の 3 つがそろっているか。
- 素材の Spine のバージョンが 3.8 か。
- 素材に `Idle` という名前のアニメーションがあるか。

Spine のバージョンは、`.skel` ファイルをテキストエディターで開くと確かめられます。ファイルの先頭近くに、`3.8.99` のようなバージョンの文字列が見えます。ほとんどの部分は文字化けして表示されますが、それで問題ありません。バージョンが 4 以上の素材は、このアプリのままでは読み込めません。読み込むには、spine-libgdx と libGDX をそのバージョンに合うものへ入れ替える必要があります。

終了した原因は、端末のログで確かめられます。端末をつないだ状態で次のコマンドを実行すると、アプリが異常終了したときのエラーが表示されます。

```sh
adb logcat -d "AndroidRuntime:E" "*:S"
```

エラーの中に `UnsatisfiedLinkError` とある場合は、素材ではなく端末との相性が原因の可能性があります。新しい Android 端末の一部は、メモリーを 16KB 単位で管理する方式を使っています。その方式の端末では、libGDX 1.10.0 に含まれる部品が読み込めない可能性があります。これまで使った端末では起きていないので、実際に起きるかは確認できていません。

## キャラクターの縁が黒っぽく見える、または白っぽく光って見える

画像の保存形式と描画の設定が合っていないときに起こります。このアプリは、画像が premultiplied alpha という形式で保存されている前提で描画しています（詳しくは [structure.md](structure.md) の「描画」を見てください）。アークナイツ以外の素材や、別の方法で書き出した素材では、画像がこの形式になっていないことがあります。

その場合は、`CharacterScene.java` の `renderer.setPremultipliedAlpha(true);` の `true` を `false` に変えて、ビルドし直してください。

## タップしても反応しない

まず、タップした場所がキャラクターの上かを確かめてください。背景画像だけが見えている場所をタップしても、反応しないように作ってあります。

反応のアニメーション（Interact）を再生している間は、次のタップを受け付けません。アニメーションが終わって待機の動きに戻ってから、もう一度タップしてください。

ホームアプリによっては、アイコンやウィジェットがない場所をタップしたときにしか、壁紙にタップが届きません。何もない場所をタップして試してください。

タップが壁紙に届いているかは、ログで確かめられます。キャラクターへのタップを受け付けると、ログに `Interact` と記録されます。Special を再生したときは `Special` と記録されます。

```sh
adb logcat -s CharacterScene
```

このコマンドは、止めるまでログを表示し続けます。止めるときは Ctrl + C を押してください。

## PC からタップの操作を送れない

`adb shell input tap` のようなコマンドで PC から画面にタップを送りたい場合、開発者向けオプションの「USB デバッグ（セキュリティ設定）」をオンにしてください。普段の利用には必要のない設定です。
