# 表示の調整

キャラクターの大きさと位置、Special を再生する間隔は、`app/src/main/java/moe/coiluck/spinewallpaper/CharacterScene.java` の先頭にある数値で決まっています。

```java
private static final float CHARACTER_SCALE = 1.5f;
private static final float CHARACTER_CENTER_Y = 0.25f;
private static final float SPECIAL_MIN_SECONDS = 10f;
private static final float SPECIAL_MAX_SECONDS = 40f;
```

数値の後ろの `f` は、Java で小数を書くときの決まりなので残してください。数値を書き換えたら、[use.md](use.md) の手順 3 のとおりにビルドして端末に入れ直すと、変更が反映されます。

## キャラクターの大きさ（CHARACTER_SCALE）

1.0 にすると、キャラクター全体がちょうど画面に収まる大きさで表示されます。2.0 ならその 2 倍、0.5 なら半分の大きさです。1.0 より大きくすると、キャラクターの一部が画面の外にはみ出します。

ここでいう「キャラクター全体」は、Spine の素材に含まれるものをすべて囲む範囲です。動的立ち絵には、人物のほかに足場や小物、鳥などが一緒に描かれていることがあり、それらも含めて測っています。スマートフォンの縦長の画面では、横幅が先に画面いっぱいになるので、1.0 のときは画面の横幅に合わせた大きさになることがほとんどです。

## キャラクターの縦の位置（CHARACTER_CENTER_Y）

キャラクターの中心を、画面のどの高さに置くかを決めます。画面の高さに対する割合で指定し、0 が画面の下端、0.5 が中央、1 が上端です。たとえば 0.25 にすると、キャラクターの中心は画面の下から 4 分の 1 の高さに来ます。

横の位置は、常に画面の中央です。

## Special を再生する間隔（SPECIAL_MIN_SECONDS と SPECIAL_MAX_SECONDS）

待機アニメーションが続いた時間が、この 2 つの値のあいだのどこかに達すると、Special を再生します。どの時点で再生するかは、毎回この範囲の中からランダムに決まります。単位は秒です。

待ち時間は、待機アニメーションを再生している間だけ進みます。タップで Interact を再生したときや Special を再生したときは、その時点で新しい待ち時間を決め直します。

Special をほとんど再生させたくない場合は、2 つの値を 100000 のような大きな数にしてください。

## アニメーションが切り替わるときの重なり

待機から Interact に切り替わるときなどは、急に姿勢が変わって見えないように、前のアニメーションと次のアニメーションを 0.3 秒かけて重ねています。この長さは、同じファイルの `setDefaultMix(0.3f)` の数値で変えられます。0 にすると、重ねずにすぐ切り替わります。
