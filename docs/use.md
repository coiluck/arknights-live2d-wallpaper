# 使い方

この文書では、キャラクターと背景の素材を用意し、アプリを端末に入れて壁紙に設定するまでの手順を説明します。キャラクターや背景を差し替えるときも、手順 1 から 3 を同じようにたどります。

## 必要なもの

- Android Studio を入れた Windows の PC。ビルドには、Android Studio と一緒に入る Android SDK と JDK 17 を使います。
- 開発者向けオプションで USB デバッグを有効にした Android 端末と、PC につなぐ USB ケーブル。
- adb コマンド。Android SDK の platform-tools フォルダーに入っています。

スマホ側では、開発者向けオプションの「USB からインストール」もオンにしておく必要があります。詳しくは [troubleshooting.md](troubleshooting.md) を見てください。

## 1. キャラクターの素材を置く

https://arknights.halyul.dev で目的のオペレーターとスキンを選び、次の 3 つのファイルをダウンロードします。

- `.skel` ファイル：キャラクターの骨格とアニメーションのデータです。`.json` 形式の場合もあります。
- `.atlas` ファイル：部品の画像が、画像ファイルのどの位置にあるかを記録したファイルです。
- `.png` ファイル：キャラクターの部品をまとめた画像です。

ダウンロードしたファイルは、名前を変えずに `app/src/main/assets/character/` に置きます。ファイル名の末尾に `.txt` が付いていても、そのままで読み込めます。

このフォルダーには 1 キャラクター分のファイルだけを置きます。前のキャラクターのファイルが残っていると、どちらが読み込まれるか決まらないので、先に削除してください。

このアプリは Spine 3.8 用の読み込み処理を使っているので、ほかのバージョンで書き出された素材は読み込めません。バージョンの確かめ方は [troubleshooting.md](troubleshooting.md) に書いてあります。

## 2. 背景画像を置く

好きな画像を 1 枚、`app/src/main/assets/background/` に置きます。形式は png か jpg です。キャラクターと同じく、このフォルダーにも画像は 1 枚だけにしてください。

画像は、画面全体を隙間なく覆う大きさに拡大または縮小されます。画面からはみ出した部分は、上下または左右で同じ幅ずつ切り取られます。スマートフォンの画面は縦長なので、縦長の画像を使うと切り取られる部分が少なくなります。フォルダーが空のときは、背景は黒になります。

## 3. ビルドして端末に入れる

端末を USB で PC につなぎ、プロジェクトのルートで次のコマンドを実行します。

```sh
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

1 行目は、端末に入れるためのアプリのファイル（APK ファイル）を作ります。2 行目は、そのファイルを端末に入れます。`-r` は、すでに入っているアプリを上書きするという指定です。

上書きでインストールした場合は、壁紙の設定が解除されずに残ります。そのため、キャラクターや背景を差し替えたあとに壁紙を設定し直す必要はありません。

インストールの途中で、端末に確認の画面が出ることがあります。そのときは端末で「インストール」を押してください。

## 4. 壁紙に設定する

端末のアプリ一覧から「Spine Wallpaper」を開くと、壁紙の設定画面が開きます。この画面には壁紙のプレビューが表示されるので、動きを確かめてから「壁紙を設定」を押してください。

機種によっては、この設定画面の代わりにライブ壁紙の一覧が開きます。その場合は、一覧から「Spine Wallpaper」を選んでください。

このアプリでできる操作は、この設定画面を開くことだけです。アプリを開いても、アプリ独自の画面は表示されません。

## 壁紙にせずに表示を確かめる

手順 4 の設定画面を開き、「壁紙を設定」を押さずに戻れば、壁紙を変えずにプレビューだけを見られます。差し替えた素材や調整の結果を確かめたいときに使えます。
